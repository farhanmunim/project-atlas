⚠ Atlas is being sunset

This API and its data feeds are winding down and will stop being refreshed and served. If you rely on Atlas, replicate the stack yourself — the full pipeline is documented and runs on free GitHub.

Replicate Atlas — London Bus Network

Atlas has been an open, keyless, CORS-enabled API for the London bus network: routes, stops, road-faithful geometry, garages, fleet, vehicles, tenders, reliability, crowding, collisions, low bridges, live diversions and real-time feeds — refreshed daily from the primary sources.

With the service sunsetting, the replication guide is the way forward: it documents how to run the entire platform yourself — every data source, the gathering, cleansing and validation pipeline, and the refresh schedules — on free GitHub, pulling directly from the primary sources with no dependency on Atlas.
