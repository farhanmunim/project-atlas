Atlas — London Bus Network API

An open, keyless, CORS-enabled API for the London bus network: routes, stops, road-faithful geometry, garages, fleet, vehicles, tenders, reliability, crowding, collisions, low bridges, live diversions and real-time feeds — refreshed daily from the primary sources.

Atlas is API-only. Start at the discovery index: GET /api/v1.
